# Evaluation

This repository includes an evaluation script for computing the Fréchet Inception Distance (MFD) between the real BraTS test set and the volumes generated by **3D-MC-SAGAN**. The evaluation is designed for the three MRI modalities used in this project: **t1n**, **t1c**, and **t2f**.


## Before you start

1. **Generate the synthetic volumes first.**
   Before running MFD, you need to run the test/inference stage of **3D-MC-SAGAN** to generate the synthetic modalities.

2. **Download the pretrained MedicalNet encoder.**
   The MFD script uses a pretrained 3D ResNet-50 feature extractor. Download the checkpoint below and keep the path for the `--pretrain_path` argument:

   - `resnet_50_23dataset.pth`
   - Hugging Face page: <https://huggingface.co/TencentMedicalNet/MedicalNet-Resnet50/blob/02061bf3be4aefd33724688f16dbcc058cdf1f13/resnet_50_23dataset.pth>

## Environment setup

Create the evaluation environment from `environment.yml`:

```bash
conda env create -f environment.yml
conda activate 3d-mc-sagan_eval
```

## Expected data layout

### Real BraTS test set

The real-data directory should contain one folder per subject, and each subject folder should include the BraTS modality files.

```text
real_test_root/
├── subject_001/
│   ├── BraTS-...-t1n.nii.gz
│   ├── BraTS-...-t1c.nii.gz
│   ├── BraTS-...-t2f.nii.gz
│   └── ...
├── subject_002/
│   └── ...
└── ...
```

### Generated data

The generated-data directory should also contain one folder per subject. Inside each subject folder, the generated modalities are expected in the following subfolders:

```text
generated_root/
├── subject_001/
│   ├── flair/
│   │   └── sample.nii.gz
│   ├── t1/
│   │   └── sample.nii.gz
│   └── t1c/
│       └── sample.nii.gz
├── subject_002/
│   └── ...
└── ...
```

In this layout:
- `t1/` is used for **t1n**
- `t1c/` is used for **t1c**
- `flair/` is used for **t2f**

## Running MFD evaluation

Once the generated samples are ready, run:

```bash
python MFD.py \
  --dataset brats \
  --data_root_real /directory/to/the/original/real/test/dataset \
  --data_root_fake /directory/to/the/generated/dataset/generated_multi_proc \
  --pretrain_path /directory/to/resnet_50_23dataset.pth \
  --path_to_activations /directory/where/you/want/to/save/activations_all_modalities \
  --modalities t1n,t1c,t2f \
  --gpu_id 0
```

## Output

The activation statistics are saved under the directory provided to `--path_to_activations`, organised by modality:

```text
activations_all_modalities/
├── t1n/
│   ├── mu_real.npy
│   ├── sigma_real.npy
│   ├── mu_fake.npy
│   └── sigma_fake.npy
├── t1c/
│   └── ...
└── t2f/
    └── ...
```

At the end of the run, the script prints the MFD score for each modality and a final summary.

## Notes

- The evaluation script is configured for the **BraTS** setting used in this project.
- The default number of samples is set to **80 per modality**, following the original evaluation behaviour.
- The script uses **GPU 0** by default in the example above. Change `--gpu_id` if needed.
